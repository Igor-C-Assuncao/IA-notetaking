# v0.3.1 known issues

The v0.3.1 artifacts remain available as a pre-release, but are not recommended for first-time installs.

- The Windows GPU engine is several gigabytes and its download cannot resume reliably after a network interruption.
- The macOS sidecar can fail during startup without exposing a useful error in the GUI.
- Startup diagnostics are limited and the service can remain on “Start services” indefinitely.

Use the v0.3.2 draft artifacts only as part of the release validation checklist. Keep v0.3.1 marked as a pre-release until v0.3.2 passes all platform checks.
